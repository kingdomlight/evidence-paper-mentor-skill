# PaperMentor 证据、质量与子 Agent 指南

---

# 证据规则

## 必须附证据的内容

研究问题、方法组成、数据集、指标、实验数值、主要结果、作者结论、明确局限，以及多篇对比中的来源事实均必须附证据。一般性阅读建议可不附证据，但不得伪装成论文事实。

## 证据结构

每条证据包含 `page`、`section`、`quote`。页码使用 PDF 物理页码，从 1 开始；若引用论文印刷页码，需额外标明。`quote` 是对应页面中的连续短原文，保留关键数字与否定词，不得拼接不同位置的文字冒充分段引文。

## 论断类型

- `paper_fact`：论文结构、方法或设置等可直接确认的内容。
- `author_claim`：作者声称的创新、优势或解释。
- `experiment_result`：论文报告的实验结果。
- `agent_inference`：基于一条或多条证据作出的分析，措辞不得超出证据强度。

## 校验规则

证据页码必须有效，原文必须在对应页面出现。自动脚本的文本匹配通过后，仍需检查原文是否真正支持论断。原文存在但语义不支持时，该论断仍不通过。

## 证据不足

无法定位证据时，删除确定性表述或改为“当前已读内容不足以确认”。不得使用模型常识、其他论文或网络信息补齐。跨章节综合结论可以列多条证据，但必须说明综合关系。

# 输出前质量检查

## 内容

- 研究问题是否准确，而非只复述标题或摘要。
- 方法步骤、实验设置和数值是否对应同一篇论文。
- 作者观点、实验结果和分析推断是否明确区分。
- 局限是否区分作者明确说明与阅读者分析。
- 是否存在绝对化、扩大适用范围或过度因果解释。

## 证据

- 页码是否有效，引文是否来自该页。
- 引文是否真正支持论断，而非只包含相似关键词。
- 多条证据是否被拼接成不存在的连续引文。
- 不可回答问题是否明确披露证据边界。

## 多篇对比

- 是否发生论文来源串线。
- 不同任务、数据集、指标和设置是否被错误排名。
- 共识、分歧和研究空白是否有相应来源或推断标记。

## 工程与表达

- 必需字段是否完整，JSON 和导出文件是否通过校验。
- 解析失败或覆盖不全是否在显著位置披露。
- 输出是否满足用户要求的深度，避免无关扩展。
- 是否泄露本地路径以外的敏感信息、密钥或无关个人数据。

# 可选子 Agent 编排

## 能力判断

仅当宿主明确提供子 Agent 调用工具时启用。不得假定特定工具名称或创建额外 `agents/` 配置。宿主不支持时，主 Agent 按同一规范串行执行，最终字段和证据要求不变。

## 启用条件

深度精读可将方法、实验和批判审阅拆成独立任务；多篇对比可按论文拆分，每篇一个任务。速读、短论文、简单追问和格式转换默认串行。单篇最多同时安排三个阅读任务，多篇首批最多三篇，其余分批处理。

## 前置步骤

先由脚本完成 PDF 检查和带页码的章节提取。给每个子 Agent 提供 `paper_id`、`task_type`、来源文件、分配章节、具体问题、证据要求，以及 `assets/contracts.json` 中的 `subagent_result_schema`。不要给多个子 Agent 重复发送整篇 PDF。

## 角色

- `method_reading`：研究问题相关方法、步骤和作者声称的创新。
- `experiment_reading`：数据集、基线、指标、结果和消融。
- `critical_review`：明确局限、证据缺口和复现风险，推断必须标记。
- `single_paper`：多篇模式下生成一篇论文的统一卡片。
- `evidence_review`：初稿合并后独立检查关键论断与证据关系。

## 合并规则

子 Agent 输出是候选结果。主 Agent 检查 `paper_id`、任务范围和返回结构，去重并处理冲突。冲突必须回到原文核查，不采用多数表决。主 Agent 统一运行证据和结构校验，再生成最终结果。

## 失败降级

子 Agent 失败、超时或结构无效时，保留其他有效结果，主 Agent 补读对应章节。先修正任务契约再考虑重新分派，不重复盲目调用。即使并行任务全部失败，也可串行完成，但不得省略证据校验或伪称调用了子 Agent。

## 禁止事项

子 Agent 不得修改 Skill 文件、访问未分配论文、联网补充事实、将推断写成作者观点，或直接覆盖主 Agent 的最终笔记。

# 测试与效果评估

## 测试层次

先运行脚本单元测试，再执行多篇 PDF 的端到端阅读。自动测试验证解析、结构和证据文本，人工核对验证总结是否准确、引文是否支持论断以及不可回答问题是否合理拒答。

## 样本

至少使用六篇论文，覆盖规范英文论文、双栏多图、公式较多、实验表格较多、长文以及中文或非标准结构。异常 PDF 单独测试降级，不与正常论文混合计算解析成功率。样本来源、许可状态和真实结果统一记录在 `references/test-report.md`。

## 每篇任务

生成一次精读笔记，回答三个事实问题、一个跨章节问题和两个不可回答问题。选择三篇同方向论文生成对比矩阵，另选两篇生成组会材料。每篇人工记录研究问题、方法、数据、指标、结论、关键证据和不可回答问题。

## 评分

内容正确性 25 分，证据可追溯性 25 分，实验理解 20 分，问答边界 15 分，结构可读性 10 分，模板完整性 5 分。目标平均分为 85 分，证据维度不低于 20 分；这些是验收目标，不是预填结果。

## 一票否决

伪造实验、数值、参考文献或原文；论文来源串线；引文存在但不支持关键结论；不可回答问题被编造；解析失败后仍伪装完整阅读，均判定该样本不通过。

## 子 Agent 测试

分别记录宿主不支持、支持、单任务失败、无效返回、证据错误和简单任务不启用等场景。比较并行与串行的事实、证据和字段一致性，并记录真实耗时，不预设提速比例。

## 回归

每次修改阅读规范或脚本后，先重跑失败样本，再重跑全部样本。实际结果写入 `references/test-report.md`，失败和未验证项必须保留。
