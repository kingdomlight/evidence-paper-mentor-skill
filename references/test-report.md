## 1. 样本范围与公开状态

- `paper01`–`paper06` 已同名原位替换为本项目原创生成的英文文本型 PDF，每篇 3 个物理页，采用双栏排版，包含规范章节、公式、算法、表格、两个虚构数据集和附录。
- 六篇 PDF 均在首页、页眉和页脚标明 `Original synthetic test paper`。方法、数据集、实验、数值、图示和参考文献均为虚构内容，不复制外部论文段落、图表或结论。
- `paper07` 和 `paper08` 保留原有原创合成边界样本，分别覆盖非标准章节和无文本层扫描降级。
- **当前 8 篇样本全部为合成样本。** 它们用于验证 Skill 的解析、证据追溯、结构校验、展示和异常停止流程，不能证明对真实论文的普遍效果。
- `manifest.csv` 将前六篇标为 `synthetic_test_data`、`original_synthetic_test_data` 和 `allowed_for_publication_with_skill`。这些样本由本项目原创生成，按清单声明允许随 Skill 公开；后两篇保留原有 `allowed` 状态。本次未新增许可证文件。
